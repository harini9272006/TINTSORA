# Tintsora — The Ultimate Color Palette Generator

**Every Color. Every Shade. Endless Possibilities.**

Tintsora is a responsive Color Palette Generator and Color Intelligence platform built for website developers, UI/UX designers, graphic designers, students, and content creators to discover, explore, compare, and copy any color or palette they need.

## Features

- **56+ Curated Ready-Made Palettes**: Immediately explore palettes across 28 categories (`Pastel`, `Vintage`, `Retro`, `Neon`, `Gold`, `Light`, `Dark`, `Warm`, `Cold`, `Summer`, `Fall`, `Winter`, `Spring`, `Monochrome`, `Earth Tones`, `Ocean`, `Forest`, `Sunset`, `Minimal`, `Vibrant`, `Muted`, `Jewel Tones`, `Wedding`, `Nature`, `Luxury`, `Corporate`, `Gaming`, `Social Media`).
- **Powerful Color Intelligence Search**: Search by common & extended color names (Coral, Lavender, Teal, Indigo, Turquoise, Mint, Burgundy, Beige, Olive, Crimson, etc.), HEX, RGB, or HSL values to generate:
  1. Exact matching color
  2. Lighter variations (Tints)
  3. Darker variations (Shades)
  4. Saturated & Desaturated variations (Tones)
  5. Closely related shades
  6. Complementary & Split-Complementary colors
  7. Analogous colors
  8. Triadic color harmonies
  9. Tetradic color combinations
  10. Monochromatic palettes
- **50–950 Shade Explorer**: Inspect any color swatch to view its full design-system shade scale (`50` to `950`), WCAG contrast ratios, related families, and matching palettes.
- **Developer Export Tools**: Copy HEX, RGB, HSL, `:root` CSS custom properties, JSON objects, or Tailwind CSS v4 theme tokens in one click.
- **Favorites & Collections**: Save favorite colors and complete palettes (with custom renaming) persisted via `localStorage`.

## Tech Stack

- **React 19** + **TypeScript**
- **Vite 6**
- **Tailwind CSS v4**
- **Lucide React Icons**
